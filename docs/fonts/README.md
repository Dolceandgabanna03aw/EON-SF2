# Aoi YUME UI Font Additions

Installed to the current user's macOS font directory (`~/Library/Fonts`):

- IBM Plex Sans Condensed: Regular, SemiBold, Bold
- IBM Plex Mono: Regular, Medium, SemiBold, Bold
- Space Grotesk: variable font

These are optional UI candidates only. The plugin still uses the existing
Avenir Next, DIN Alternate, and Snell Roundhand settings.
